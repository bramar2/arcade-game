# arcade-game: Arcade game made with C++ using SDL3
## Dependencies
- SDL3
- SDL3_ttf
- bramar2/json (custom)
## Building
On root, run the following commands:
- `cmake -S . -B build/`
- `cmake --build build/`


The executable should be in build/arcade-game.exe. Make sure you have SDL3 and SDL3_ttf installed.
